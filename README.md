# Temporal GIS — Frontend-only static POC

Angular + Esri ArcGIS Maps SDK v5.1; **NO backend / database / AI / image-difference detection**.

Work in progress: see `HANDOFF.md` for current status and next steps.

## Quick start

Requires Node.js 22.12+ and an internet connection to install packages and load the ArcGIS SDK, basemap and Wayback imagery.

```bash
npm install
npm start
# http://localhost:4200
```

## What to demo

1. **Source** picks the data shown on both maps:
   - `Satellite` (default): real Esri World Imagery Wayback imagery over about 3 × 3 km of Al Madinah (Bani Muawiyah, east of the Prophet's Mosque), with 32 change polygons traced by hand: building progress, new buildings, roads, earthworks, vehicles and demolitions. Any month from Jan 2018 to Mar 2026 can be picked; each shows the latest imagery up to it, and the timeline marks the 10 months with new imagery. It opens on the 3-month window Mar → Jun 2025.
   - `Images`: five self-generated georeferenced raster images with 105 synthetic buildings.
   - `Load test 20K`: 20,000 synthetic buildings with 30–100 vertices each, over OpenStreetMap, with an FPS readout.
2. Pan/zoom/rotate either map: the other follows, including mouse-wheel zoom.
3. Pick a month and year for either map. Months with no epoch in that year are greyed out. A solid polygon is a footprint that exists in that map's epoch. A dashed outline is a footprint that exists only in the other epoch. Modified buildings show both.
4. Pick a change in the right sidebar to fly to that feature.
5. Switch 2D / 3D: 3D footprints are extruded according to building heights. Both maps still synchronize.
6. Use the multi-epoch timeline to set either epoch, see the change count per period, or press Play. The Added / Removed / Modified filters apply to both the list and the map.

## Concept and limits

- Date differences are **metadata lookups** for known static snapshots; no spatial difference algorithm and no remote processing is performed.
- Epochs are `YYYYMM` integers (`202403` is March 2024), in the data files and in the app.
- The change list and counts are scoped to the **currently visible map viewport** after navigation settles. The list shows at most 200 rows.
- Wayback dates are Esri **release** dates, not capture dates. Check Esri's terms of use before going beyond a POC.
- All footprints are WGS84 polygon rings. Buildings render through a client-side `FeatureLayer`; change highlights render through a `GraphicsLayer`.
- 2D <-> 3D switching reinitializes the pair of views near the current geographic center and zoom. Exact pixel-level equivalence is not possible across map and perspective views.
- `Images` and `Load test 20K` coordinates and data are fictional.

## Data files

- `src/app/demo-data.ts` — synthetic 105-building dataset for `Images`.
- `src/app/real-data.ts` — Wayback release IDs and hand-traced features for `Satellite`. The tracing inputs and converter are in `tools/trace/`.
- `public/epochs/*.png` — synthetic static orthophotos.
- `public/data/load-test.json` — about 33 MB, generated by `node tools/generate-load-test.mjs`.
- `src/app/app.component.ts` / `.html` — views, sync, layers, UI state.
